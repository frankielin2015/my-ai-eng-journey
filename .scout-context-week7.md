## 2. Week 7 spec (verbatim key requirements)

**Project:** "An end-to-end observability pipeline for agent runs. Wrap an LLM call, capture the trace (prompt, tool calls, latency, tokens, cost), emit it to Postgres, visualize in Grafana." Rationale: "your SRE background is your moat."

**Architecture / deliverables:**
- `agent_trace.py` — Python decorator / context manager wrapping an agent run, records: prompt, response, tool calls (name, args, duration, status), latency by step, total tokens, estimated cost. Emits structured JSON to **Postgres** (plain tables, no pgvector).
- **Grafana dashboard over Postgres**: time-series (runs/hour, success vs failure, p50/p95 latency), breakdowns (tool-call counts, error rate by tool, cost per day), single-run drill-down (timeline of a run's spans).
- README: problem statement, mermaid architecture diagram, cost/latency reasoning, dashboard screenshots.
- Hard requirement: **new repo `agent-observability/` on GitHub** — the bar for calling the week "shipped."
- Stretch (not blocking): 60-sec demo video — can slip into Week 8.
- Success test: "Show one bad agent run. Click through to the failing tool call. Tell me what it cost."
- Materials: Anthropic observability/tracing cookbook, Langfuse `@observe()` quickstart, OpenTelemetry Python getting-started + traces concepts.
- Tail-of-week: light resume pass (not full rewrite) if time allows.
